배포 방식 선택

실제 웹서비스는 Vercel 배포를 추천합니다. Next.js 앱은 보통 GitHub Pages의 단순 index.html 방식이 아니라, GitHub 저장소를 Vercel에 연결해 배포합니다.

  1. GitHub에 새 저장소를 만듭니다.
  2. 이 프로젝트 파일 전체를 저장소 루트에 업로드합니다.
  3. Vercel에서 해당 GitHub 저장소를 Import 합니다.
  4. Vercel 환경 변수에 Supabase URL과 anon key를 입력합니다.
  5. Deploy 버튼을 누릅니다.

Supabase DB 연결 순서

  1. Supabase에서 새 프로젝트를 만듭니다.
  2. SQL Editor에서 supabase/schema.sql 내용을 실행합니다.
  3. SQL Editor에서 supabase/seed.sql 내용을 실행합니다.
  4. Project Settings → API에서 Project URL과 anon/public key를 복사합니다.
  5. 로컬에는 .env.local, Vercel에는 Environment Variables에 아래 값을 넣습니다.
NEXT_PUBLIC_SUPABASE_URL=https://프로젝트아이디.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=복사한_anon_public_key

중요: service role key는 브라우저, GitHub, Vercel 공개 환경 변수에 절대 넣지 않습니다.

실제 앱 화면은 src/app/page.tsx에서 시작합니다. GitHub 업로드 후 Vercel로 배포하세요.
